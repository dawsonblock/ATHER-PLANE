# DREAM-RSI adoption matrix — v2.33

Source: *Dream-RSI: Recursive Self-Improvement through Evolving Worlds*,
arXiv:2609.14858v1.

| Source mechanism | v2.33 Aether treatment |
|---|---|
| Online exploration produces structured history | Adopted for real training-allocation execution |
| History becomes replay worlds | Adopted; grounded outcomes only |
| Same decision interface online/replay | Adopted as `awa-training-allocation-v2` |
| Choose branches, parallelism, stopping | Adapted to factor/collector/budget/world allocation |
| Quality-cost-parallelism replay objective | Exact-paper mode plus separate Aether mode |
| Iterative policy-development feedback | Adopted as bounded multi-round declarative revision |
| Best replay policy redeployed online | Hardened: paired grounded qualification required first |
| Underlying agent/evaluator fixed | Adopted and SHA-bound |
| Arbitrary executable policy-code rewriting | Not adopted |
| Replay invents outcomes outside history | Explicitly forbidden |
| Historical result alone counts as empirical proof | Explicitly forbidden |

The source paper demonstrates the mechanism in discovery domains. v2.33 treats
that as evidence that the method is worth testing, not as evidence that it
already improves embodied reinforcement learning.
