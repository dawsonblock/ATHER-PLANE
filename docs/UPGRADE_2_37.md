# Aether v2.37 — Progressive Capability Curriculum

v2.37 freezes the action-time Agent Runtime and converts the training roadmap into an executable, ordered empirical gate.

## Why

The repository already contains the major candidate mechanisms. The main remaining risk is spending large budgets on later capabilities before basic control, memory, dynamics reliability, planner value, visual representation, and transfer are demonstrated.

## Ordered gate

`awa-v2-progressive-capability` inspects an evidence directory and reports the longest contiguous prefix of passed phases. A later artifact cannot bypass a missing earlier prerequisite.

The canonical path is: preflight → structured 2K → structured 10K → structured 25K → temporal-memory ablation → held-out world-model horizon gate → grounded planner benefit → adaptive-compute value → real V-JEPA pixel 5K → physical planner schedule → compositional generalization → five-seed DREAM-RSI → unseen-map transfer → matched external baseline → manual 250K+ scale decision.

## World-model horizon gate

`awa-v2-world-model-horizon-gate` consumes held-out measurements for each rollout horizon. A point must satisfy prediction-error, calibration-error, and sample-count thresholds, and accepted horizons must form a contiguous reliable prefix. The largest accepted horizon becomes the permitted planning horizon for subsequent experiments.

This gate intentionally does **not** claim that planning helps. Realized planner value remains a separate grounded ablation gate.

## Evidence boundary

No new real environment result is shipped in this release. v2.37 is execution governance, not a benchmark result.
